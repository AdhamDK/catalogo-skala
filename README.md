# catalogo-skala
Catalogo Dist Ontiveros Only Skala

## Publicación en Netlify

El sitio es estático y sus archivos están en `catalogo-skala/`. El archivo
`netlify.toml` configura esa carpeta como directorio de publicación para que
`index.html` se sirva en la raíz del dominio. No necesita comando de compilación.

Para publicar cambios, subilos a la rama `main` del repositorio conectado a Netlify.
